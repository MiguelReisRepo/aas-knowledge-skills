# Update watch: upstream sources behind the knowledge skills

Last verified: 2026-10-28. Each skill's pinned sources (with sha256) are in `skills/<skill>/VERSION.json`.
Its eval questions are in `skills/<skill>/evals/evals.json`, and each one cites a literal quote in one of these sources.

When a watched source changes:
1. Mirror or vendor the new file.
2. Run `python3 tools/run-evals.py selftest`. A quote that moved or vanished fails with the item id.
3. Re-check the points listed below. Update SKILL.md, evals and VERSION.json (version bump and `last_verified`).
4. Re-run a blind answer pass and grade it: `python3 tools/run-evals.py grade answers.json`.

Off-repo sources are reached through the aliases in `tools/sources.json` (`idta-pdfs:`, `idta-specs:`, `idta-specs:`).
Override them per machine with `AAS_SOURCES_<ALIAS>`.
